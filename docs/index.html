Co warto przygotować?

Dla AD: dostęp do domeny, RSAT i delegowane uprawnienia. Dla Microsoft 365: rejestrację aplikacji Entra i wymagane zgody. Dla Exchange: moduł ExchangeOnlineManagement i odpowiednie role.

FAQ

Zanim zaczniesz.

Czym różnią się Free i Pro?

Free pozwala poznać aplikację, skonfigurować środowisko i przygotować podgląd. Pro odblokowuje wykonywanie procesów administracyjnych i funkcje oznaczone PRO. Plan aktywujesz w tej samej aplikacji.

Czy potrzebuję lokalnego Active Directory?

Nie dla każdego trybu. On-Premises używa lokalnego AD, Hybrid łączy AD i Microsoft 365, a Full Cloud jest przeznaczony dla środowiska Entra ID / Microsoft 365. Obecny Mover wymaga lokalnego AD.

Czy muszę osobno pobrać updater?

Nie. Do rozpoczęcia pracy wystarczy aplikacja. Przy aktualizacji AdminForge pobiera wymagany updater i sprawdza podpis manifestu oraz sumy SHA-256. Instalację uruchamiasz samodzielnie.

Czy to oficjalny produkt Microsoft?

Nie. AdminForge jest niezależną aplikacją administracyjną. Active Directory, Microsoft 365, Entra ID i Exchange to produkty oraz znaki ich właścicieli.
