Public binary releases of AdminForge for Windows. Application source code remains private. The `docs/` directory contains only the static showcase website and screenshots with demonstration data.

## Strona / Website

GitHub Pages publishes `main:/docs`. Updates to website files deploy the site automatically. The download button uses the latest public stable release; if the GitHub API is unavailable, it opens the releases page. No GitHub token or application secrets are used by the site.

Screenshots show a development build and may differ from the latest public release. They contain demonstration data only.
